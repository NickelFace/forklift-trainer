# Forklift TLILIC0003 — тренажёр

Веб-тренажёр для подготовки к письменному экзамену на австралийскую лицензию оператора
вилочного погрузчика (TLILIC0003, High Risk Work Licence class LF).

**Прод:** https://fork.maks.top

## Что внутри

| Режим | Что делает |
|---|---|
| **Карточки** | 68 экзаменационных вопросов: короткие тезисы для заучивания, схема, полный английский ответ и русский перевод по кнопке. Интервальные повторения (Лейтнер: 1 → 3 → 7 → 21 день), фильтр по 8 разделам, ссылка на страницу ответов в PDF |
| **Квиз 68** | Те же 68 вопросов с четырьмя вариантами ответа (порядок перемешивается), наборы 20 / все / по порядку, порог 80 %, разбор + тезисы + схема после каждого ответа |
| **Экзамен 60** | Отдельный банк из 60 тестовых вопросов, наборы 10 / 30 / 60, порог 80 % |
| **Ошибки** | Всё, что завалено в квизе, экзамене и карточках, копится отдельно + прогон только ошибочных |
| **Схемы** | 25 рисунков (inline SVG): точка опоры и load centre, треугольник устойчивости, рампы, зоны ЛЭП, контакт с проводом, data plate, навески и т.д. — с пояснениями «с нуля» |
| **Документ** | Три PDF постранично с оглавлением, свайпом и скачиванием: ответы на 68 вопросов (17 стр.), учебное пособие (45 стр.), конспект Study Guide (39 стр.) |
| **Все вопросы** | Полнотекстовый поиск по вопросам, тезисам и ответам |

Прогресс и история экзаменов — в `localStorage` браузера. Ни бэкенда, ни аналитики, ни зависимостей.

Горячие клавиши: `Пробел` — показать ответ, `1` / `2` — знаю / повторить, `A`–`D` — выбор варианта, `Enter` — дальше.

## Структура

```
index.html             тренажёр (HTML + CSS + JS, без зависимостей), грузит data.json через fetch
figs.js                25 схем: window.FIG[id] = { title, ru, svg, notes[] }
data.json              банк вопросов: { quiz: [68 открытых + варианты + тезисы], mc: [60 тестовых] }
doc/                   три PDF + их страницы в JPEG (doc/<id>/p-NN.jpg), оглавления — в DOCS в index.html
build/build.py         собирает офлайн-версию одним файлом → dist/forklift-trainer.html (без doc/)
sources/               исходные PDF (в git не попадают, см. .gitignore)
dist/                  офлайн-сборка одним файлом
```

Если `data.json` в папке ещё нет — он вынимается из готовой офлайн-версии тренажёра
(`forklift-trainer.html`, лежит рядом с папкой проекта):

```bash
python3 build/extract_data.py
```

## Локальный запуск

`fetch('./data.json')` не работает через `file://`, поэтому:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Либо собрать автономный файл, который открывается двойным кликом:

```bash
python3 build/build.py     # → dist/forklift-trainer.html
```

## Формат данных

```jsonc
// data.json → quiz[] — открытые вопросы: карточки + квиз
{
  "id": "q17", "n": 17,
  "section": "Loads, stacking and travelling",
  "q": "How high should your load be raised when travelling?",
  "a_en": "Just clear of the ground — approximately 100–150 mm ...",
  "a_ru": "Чуть выше земли — примерно 100–150 мм ...",
  "key": ["Just clear of the ground — about 100–150 mm", "Mast tilted back ..."],  // тезисы для заучивания
  "options": ["Just clear of the ground ...", "At eye level ...", "..."],        // 4 варианта, correct — индекс
  "correct": 0,                       // в данных верный всегда первый; порядок перемешивается при показе
  "explain_ru": "100–150 мм над землёй ...",
  "fig": "travel"                     // id схемы из figs.js (необязательно)
}

// data.json → mc[] — вопросы с вариантами, режим экзамена
{
  "id": "mc9", "topic": "Powerlines",
  "q": "You are working in NSW near a 200kV overhead power line...",
  "options": ["3.0 m", "6.0 m", "8.0 m", "10 m"],
  "correct": 1,                       // 0-based индекс верного варианта
  "explain_ru": "Линия выше 132 кВ, но не выше 330 кВ → 6,0 м.",
  "source": "Разд. 3, таблица NSW"
}
```

Чтобы добавить или поправить вопрос — правится только `data.json`, код трогать не нужно.
Новая схема — объект в `figs.js` и его id в поле `fig` нужных вопросов.

Страницы PDF для вкладки «Документ» рендерятся так (110–130 DPI, JPEG):

```bash
pdftoppm -r 130 -jpeg -jpegopt quality=80 sources/forklift_quiz_answers.pdf doc/answers/p
```

## Источники и оговорки

Банк вопросов собран из двух учебных материалов:

- `Licence to Operate a Forklift Truck — Quiz`, model answers, вопросы 1–68 (Licences4Work, v3)
- `TLILIC0003 Forklift Theory — National Study Guide`, v1.3, July 2023 (Licences4Work) + русский конспект

Исходные PDF Licences4Work **в репозиторий не коммитятся** — это чужой учебный контент. Лежат локально в `sources/`.
В `doc/` опубликованы только собственные производные материалы: ответы на вопросы и два русских конспекта.

Тренажёр — учебное пособие, а не официальный материал RTO. Точные значения (зоны у ЛЭП, штрафы,
процедуры) различаются по штатам: сверяйся с регулятором своего штата (SafeWork NSW, WorkSafe VIC/QLD),
инструкцией производителя и правилами площадки — они имеют приоритет.

**Два места, где источники расходятся между собой:**

1. Порядок действий при контакте с ЛЭП. В Quiz первый шаг — «оставаться на машине», в Study Guide —
   `Warn people to stay away`. В тесте использована версия Study Guide (там шаги пронумерованы как
   экзаменационные).
2. Газ при заряде батареи. Конспект в одном месте пишет `hydrogen sulphide`, в разделе сверки — что
   реально выделяется водород. Вопрос про это из банка исключён.
